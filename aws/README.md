# AWS Configuration
This directory contains documentation for the AWS infrastructure used in the project.

Service	                                                                           Purpose
Amazon VPC	                                                                       Provides isolated network infrastructure
EC2	                                                                               Hosts the application server
Apache Tomcat	                                                                     Runs the web application
Amazon RDS	                                                                       Hosts the MySQL database
Security Groups                                                                    Controls inbound and outbound traffic
Subnets	                                                                           Separates public and private resources
Internet Gateway	                                                                 Provides internet connectivity for public resources
IAM	                                                                               Manages AWS permissions and access
CloudWatch	                                                                       Used for monitoring AWS resources
